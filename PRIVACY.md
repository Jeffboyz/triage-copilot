# Privacy Policy — Triage Copilot

Last updated: 21 November 2026

Triage Copilot is a Rovo agent for Jira, built with Atlassian Forge for the
Atlassian Codegeist 2026 hackathon.

## What the app does

When a user asks it to triage a Jira issue, the app reads that issue's data
(summary, status, priority, assignee, comments, linked goals and teams)
from the user's own Atlassian site, and produces a triage recommendation
(suggested priority, suggested owner, duplicate check, first-draft plan).
It posts the recommendation as a comment only when the user explicitly
asks it to.

## Data collection and storage

The app does **not** collect, store, or transmit personal data to any
external server. All processing happens inside Atlassian Forge and Rovo;
no issue data, user data, or personal data leaves the user's Atlassian
site. The app has no database, no analytics, no tracking, and no
third-party data sharing.
