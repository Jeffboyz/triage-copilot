# Terms of Service — Triage Copilot

Last updated: 21 November 2026

Triage Copilot is a Rovo agent for Jira, built with Atlassian Forge for the
Atlassian Codegeist 2026 hackathon. It is free to install and use.

## Use

The app provides AI-generated triage suggestions (priority, owner,
duplicates, plan) for Jira issues. Suggestions are recommendations only —
users should review them before acting on them. Posting a recommendation
as a comment happens only when the user explicitly asks for it.
